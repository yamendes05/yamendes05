## Sobre mim

Sou estudante de Engenharia da Computação e direciono meus estudos para o desenvolvimento back-end. Tenho trabalhado na construção de APIs REST com Java e Spring Boot, aplicando organização em camadas, validação de dados, tratamento de exceções e testes automatizados.

Também tenho conhecimentos em Python e fundamentos de computação em nuvem. Gosto de aprender construindo projetos práticos e evoluindo a qualidade do código e da documentação.
